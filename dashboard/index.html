Set aside — token-less, but not launching their own

These record no token, but they are the kinds of product the house watchlist rule leaves out: exchange venues, bridge infrastructure, wrapped or staked wrappers, and versioned successors of protocols whose token already trades. They get no implied value here. The watchlist is the floor, not the ceiling, so the ranked board may still hold protocols it does not name.

How the board is built

Every protocol in the sealed snapshot is scored by one model, dashboard/engine.js, the same code that produced board.json:

fair value = TVL × comparable multiple × momentum × tenure
implied value = fair value × launch odds

The comparable multiple is the median market-cap-to-TVL ratio of the tokened protocols in the same category (the global median covers thin categories). Momentum uses the 7-day TVL change, bounded; tenure rewards months already spent live without a token. The launch odds blend size, tenure, traction and the category's launch climate, measured on this snapshot; watchlisted protocols start from a higher odds base, staking-family categories from a lower one. Farm plans are chosen by category text and sized by the model's ticket economics; expected farmer value fades steeply with ticket size against TVL, calibrated so a $100 ticket on a $8M protocol and a $1,100 ticket on a $2.75B one each expect a few hundred dollars.

Implied values are this entry's own model output on the sealed DefiLlama snapshot — a ranking aid, never a prediction that a token will come, and never a claim make.fun makes. Nothing here is financial advice.
